---
title: Signatures
description: HMAC-SHA256 webhook signing and verification.
---

Every webhook delivery is signed with HMAC-SHA256 using the endpoint's signing secret.

## Signing format

The signed content is `"{timestamp}.{payload}"`. The signature is returned in the format `v1=<hex>`.

### Headers sent with each delivery

| Header | Example |
|--------|---------|
| `X-Relay-Signature` | `v1=5257a869...` |
| `X-Relay-Timestamp` | `1704067200` |

## Signing

```go
import "github.com/xraph/relay/signature"

sig, err := signature.Sign(payload, secret, timestamp)
if err != nil {
    // signature.ErrNoSecret: the secret was empty or only whitespace.
}
// sig == "v1=5257a869e4c5a2b5..."
```

`Sign` refuses an empty or whitespace secret and returns `signature.ErrNoSecret`
instead of a signature.

It has to. HMAC will happily produce a digest from an empty key, and that
digest verifies against the same empty key, so it comes out as a well-formed
`v1=` signature that nothing on the wire distinguishes from a real one. Anybody
who knows the payload and the timestamp can reproduce it, and a receiver doing
verification correctly would accept it. Refusing in `Sign` itself means no
caller can forget the check.

## Verification

```go
ok := signature.Verify(payload, secret, timestamp, receivedSignature)
```

`Verify` returns `false` for an empty or whitespace secret, whatever signature
you pass it. There is no signature that can be correct under a key that does
not exist.

## Endpoints without a secret

Relay does not deliver to an endpoint with no signing secret. The delivery fails
with `endpoint has no signing secret` and ends up in the dead letter queue.

`Endpoints().Create` generates a secret whenever you do not supply one, and it
treats a secret of spaces as not supplied, so this only happens to an endpoint
written to the store directly. To check before upgrading:

```go
unsigned, err := r.Endpoints().ListUnsigned(ctx, "")
```

An empty tenant checks every tenant, and so does a tenant of only spaces, which
is no tenant at all. Pass a real one to check just that tenant. It reads every
page the store has, so an empty result means you have none, not that it gave up
partway. Rotate a secret onto anything it returns with
`Endpoints().RotateSecret`.

## Secret format

Secrets are generated with `signature.GenerateSecret()`:

```
whsec_<64 hex characters>
```

Format: `whsec_` prefix + 32 random bytes encoded as hex (70 characters total).

## Receiver-side verification example

```go
func webhookHandler(w http.ResponseWriter, r *http.Request) {
    body, _ := io.ReadAll(r.Body)
    sig := r.Header.Get("X-Relay-Signature")
    ts := r.Header.Get("X-Relay-Timestamp")

    timestamp, _ := strconv.ParseInt(ts, 10, 64)

    if !signature.Verify(body, mySecret, timestamp, sig) {
        http.Error(w, "invalid signature", http.StatusUnauthorized)
        return
    }

    // Process the webhook...
    w.WriteHeader(http.StatusOK)
}
```
