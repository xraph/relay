The `observability` package records delivery metrics and OpenTelemetry spans. The Forge extension wires both for you, using the app's metrics. Outside Forge you pass them to `relay.New` yourself.

## Metrics

`NewMetrics` takes a `github.com/xraph/go-utils/metrics` `MetricFactory`. Inside a Forge extension that's `fapp.Metrics()`; standalone, `metrics.NewMetricsCollector(name)` works:

```go
import (
    gumetrics "github.com/xraph/go-utils/metrics"
    "github.com/xraph/relay"
    "github.com/xraph/relay/observability"
)

r, err := relay.New(
    relay.WithStore(store),
    relay.WithMetrics(observability.NewMetrics(gumetrics.NewMetricsCollector("relay"))),
    relay.WithTracer(observability.NewTracer()),
)
```

Relay doesn't register anything with Prometheus on its own. Forge's metrics exporter serves these alongside the app's other metrics.

### Available metrics

| Metric | Type | Description |
|--------|------|-------------|
| `relay_events_sent_total` | Counter | Total events submitted |
| `relay_deliveries_total` | Counter | Delivery attempts, labelled by `status` (`delivered`, `failed`, `retried`) |
| `relay_delivery_latency_seconds` | Histogram | HTTP request latency per delivery |
| `relay_dlq_size` | Gauge | Deliveries moved to the DLQ since the process started. The engine only increments it; replay and purge don't lower it |
| `relay_pending_deliveries` | Gauge | The last pending count read from the store (`CountPending`) |

### Recording deliveries

The delivery engine calls this after every attempt. You only call it yourself if you build your own sender:

```go
metrics.RecordDelivery("delivered", 0.245)
metrics.RecordDelivery("failed", 1.023)
```

## OpenTelemetry tracing

```go
import "github.com/xraph/relay/observability"

tracer := observability.NewTracer()

ctx, span := tracer.StartDeliverySpan(ctx, deliveryID, eventID, endpointID)
defer tracer.EndDeliverySpan(span, statusCode, latencyMs, errMsg)
```

Each delivery span includes attributes:
- `relay.delivery_id`
- `relay.event_id`
- `relay.endpoint_id`
- `http.status_code`
- `relay.latency_ms`
- `relay.error` (if present)
