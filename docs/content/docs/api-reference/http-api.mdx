title: HTTP Admin API
description: Complete reference for the Relay admin API endpoints.
---

The admin API is served by `api.NewHandler()`. Mount it under a prefix of your choice. All requests and responses use JSON.

These paths are the plain handler's. The [Forge extension](/docs/guides/forge-extension) mounts the same operations under its base path plus `/v1` (for example `/relay/v1/endpoints`), with `:endpointId`, `:eventId` and `:dlqId` path parameters.

Neither version has authentication. Put your own in front of it.

## Setup

```go
handler := api.NewHandler(r.Store(), r.Catalog(), r.Endpoints(), r.DLQ(), logger)
mux.Handle("/webhooks/", http.StripPrefix("/webhooks", handler))
```

## Event Types

### Register event type

```http
POST /event-types
Content-Type: application/json

{
  "name": "invoice.created",
  "description": "Fired when a new invoice is generated",
  "group": "billing",
  "version": "2025-01-01",
  "schema": {"type": "object"},
  "metadata": {"team": "billing"}
}
```

**Response:** `201 Created`

### List event types

```http
GET /event-types?group=billing&include_deprecated=true&limit=20&offset=0
```

`limit` defaults to 50 on every list route.

**Response:** `200 OK` with array of event types.

### Get event type

```http
GET /event-types/{name}
```

### Deprecate event type

```http
DELETE /event-types/{name}
```

Soft-deletes the event type and answers `204 No Content`. Sending events with this type will fail.

## Endpoints

### Create endpoint

```http
POST /endpoints
Content-Type: application/json

{
  "tenant_id": "tenant-acme",
  "url": "https://acme.example.com/webhook",
  "event_types": ["order.*", "invoice.created"],
  "headers": {"X-Custom": "value"},
  "rate_limit": 100,
  "metadata": {"env": "production"}
}
```

**Response:** `201 Created` with endpoint including generated `id` and `secret`.

### List endpoints

```http
GET /endpoints?tenant_id=tenant-acme&limit=20&offset=0
```

`tenant_id` is required here; without it you get a 400.

### Get endpoint

```http
GET /endpoints/{id}
```

### Update endpoint

```http
PUT /endpoints/{id}
Content-Type: application/json

{
  "url": "https://new-url.example.com/webhook",
  "event_types": ["order.*"],
  "rate_limit": 200
}
```

### Delete endpoint

```http
DELETE /endpoints/{id}
```

### Enable / Disable

```http
PATCH /endpoints/{id}/enable
PATCH /endpoints/{id}/disable
```

### Rotate secret

```http
POST /endpoints/{id}/rotate-secret
```

**Response:** `200 OK` with `{"secret": "whsec_..."}`.

## Events

### Send event

```http
POST /events
Content-Type: application/json

{
  "type": "order.created",
  "tenant_id": "tenant-acme",
  "data": {"order_id": "ORD-001", "amount": 99.99},
  "idempotency_key": "order-ORD-001"
}
```

**Response:** `202 Accepted` with the stored event.

### List events

```http
GET /events?type=order.created&limit=20&offset=0
```

### Get event

```http
GET /events/{id}
```

## Deliveries

### List deliveries for endpoint

```http
GET /endpoints/{id}/deliveries?state=pending&limit=20&offset=0
```

## Dead Letter Queue

### List DLQ entries

```http
GET /dlq?tenant_id=tenant-acme&limit=20&offset=0
```

### Replay single entry

```http
POST /dlq/{id}/replay
```

### Bulk replay

```http
POST /dlq/replay
Content-Type: application/json

{
  "from": "2025-01-01T00:00:00Z",
  "to": "2025-01-02T00:00:00Z"
}
```

Replays every entry that failed between `from` and `to` (RFC 3339) and answers `{"replayed": <count>}`. A single replay answers `204 No Content`, `404` for an unknown entry and `409` for one already replayed.

## Stats

### System statistics

```http
GET /stats
```

Returns `{"pending_deliveries": <n>, "dlq_size": <n>}`.

## Error responses

All errors return a JSON object with an `error` field:

```json
{
  "error": "endpoint not found"
}
```

| Scenario | Status Code |
|----------|-------------|
| Resource not found | 404 |
| Invalid input / validation | 400 |
| Duplicate idempotency key | 202 (no-op) |
| Internal error | 500 |
