This is a reference map of every package in the module, what it exports, and when you'd use it.

## Root package

Import: `github.com/xraph/relay`

| Export | Type | Purpose |
|--------|------|---------|
| `Relay` | struct | Root webhook delivery engine |
| `New(opts...)` | func | Constructor (requires `WithStore`) |
| `Option` | type | Functional option type |
| `Config` | struct | Runtime configuration |
| `DefaultConfig()` | func | Returns sensible defaults |
| `DefaultRetrySchedule` | var | `[5s, 30s, 2m, 15m, 2h]` |
| `WithStore`, `WithLogger`, `WithConcurrency`, etc. | funcs | Configuration options (`WithShutdownTimeout` is stored but not read yet) |
| `ErrNoStore`, `ErrEventTypeNotFound`, `ErrEndpointNotFound`, etc. | errors | Sentinel errors |

## id

Import: `github.com/xraph/relay/id`

TypeID-based identifiers. See [Identity](/docs/concepts/identity).

| Export | Purpose |
|--------|---------|
| `ID` | The identifier type (single struct) |
| `Prefix` | Prefix type for entity classification |
| `New(prefix)` | Generate a new ID |
| `Parse(s)` | Parse a TypeID string |
| `ParseWithPrefix(s, prefix)` | Parse with prefix validation |
| `MustParse(s)`, `MustParseWithPrefix(s, prefix)` | Parse or panic |
| `Nil` | Zero-value ID |
| `PrefixEventType`, `PrefixEndpoint`, `PrefixEvent`, `PrefixDelivery`, `PrefixDLQ`, `PrefixAttempt`, `PrefixSecret` | Prefix constants |
| `NewEventTypeID()`, `NewEndpointID()`, etc. | Convenience constructors |
| `ParseEventTypeID(s)`, `ParseEndpointID(s)`, etc. | Convenience parsers |

## signature

Import: `github.com/xraph/relay/signature`

| Export | Purpose |
|--------|---------|
| `Sign(payload, secret, timestamp) (string, error)` | Compute HMAC-SHA256 signature. Returns `ErrNoSecret` for an empty or whitespace secret |
| `Verify(payload, secret, timestamp, sig)` | Verify signature. Always `false` for an empty or whitespace secret |
| `ErrNoSecret` | Returned by `Sign` when the secret is absent |
| `GenerateSecret()` | Generate `whsec_` signing secret |
| `Signer` | Stateless signer struct |

## api

Import: `github.com/xraph/relay/api`

| Export | Purpose |
|--------|---------|
| `Handler` | HTTP admin API handler |

## store

Import: `github.com/xraph/relay/store`

| Export | Purpose |
|--------|---------|
| `Store` | Aggregate interface composing all subsystem stores |

Implementations: `store/memory`, `store/postgres`, `store/sqlite`, `store/mongo` and `store/redis`. The conformance suites are in `store/storetest`.

## extension

Import: `github.com/xraph/relay/extension`

| Export | Purpose |
|--------|---------|
| `Extension` | Forge extension adapter |
| `New(opts...)` | Constructor |
| `ExtOption` | Extension option type |
| `Config`, `DefaultConfig()` | Extension config; embeds `relay.Config` |
| `WithStore`, `WithBasePath`, `WithConfig`, `WithRelayOption`, `WithDisableRoutes`, `WithDisableMigrate`, `WithRequireConfig`, `WithGroveDatabase`, `WithGroveKV` | Options. `WithPrefix` and `WithDisableMigrations` are deprecated aliases |
| `Relay()`, `API()` | The engine and the Forge API, set during `Register` |
| `Handler(store, catalog, epSvc, dlqSvc)` | Create the plain admin API handler |
| `BasePath()` | The configured base path (default `/relay`); `Prefix()` is a deprecated alias |
